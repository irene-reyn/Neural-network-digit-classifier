# Neural Network Digit Classifier

This project implements a simple neural network to classify handwritten digits (0–9) using the MNIST dataset.

## Overview
The model is trained using a feedforward neural network implemented in PyTorch. It demonstrates key concepts such as forward propagation, loss minimization, and model evaluation.

## Tools Used
- Python
- PyTorch
- Google Colab

## Results
The model achieves approximately 90% accuracy on the MNIST test dataset.

## How to Run
Open the notebook in Google Colab or Jupyter Notebook and run the cells sequentially.
